========
Rapports
========

Les rapports financiers vous donnent une vue d'ensemble sur la santé
financière de votre activité.

Tableau de bord
===============

Le tableau de bord principal affiche les indicateurs clés :

- **Chiffre d'affaires** du mois / de l'année
- **Factures en attente** de paiement
- **Créances en retard** (impayés)
- **Dettes fournisseurs** en cours
- **Trésorerie** disponible

Rapports disponibles
====================

Chiffre d'affaires
------------------

Analysez votre chiffre d'affaires par :

- **Période** : jour, semaine, mois, trimestre, année
- **Client** : CA par client
- **Produit/Service** : CA par article vendu
- **Commercial** : CA par vendeur (si applicable)

Journal des ventes
------------------

Liste chronologique de toutes les factures émises avec :

- Numéro de facture
- Date d'émission
- Client
- Montant HT, TVA, TTC
- État du paiement

Journal des achats
------------------

Liste chronologique de toutes les factures fournisseurs avec :

- Numéro de facture fournisseur
- Date de réception
- Fournisseur
- Montant HT, TVA, TTC
- État du paiement

Balance âgée clients
--------------------

Vue des créances clients classées par ancienneté :

- Non échu
- 0-30 jours de retard
- 31-60 jours de retard
- 61-90 jours de retard
- Plus de 90 jours de retard

Déclaration de TVA
------------------

Récapitulatif de la TVA pour la période :

- **TVA collectée** : sur les ventes
- **TVA déductible** : sur les achats
- **TVA à payer** : différence collectée - déductible

Export des données
==================

Tous les rapports peuvent être exportés en :

- **PDF** : pour impression et archivage
- **CSV/Excel** : pour traitement dans un tableur
