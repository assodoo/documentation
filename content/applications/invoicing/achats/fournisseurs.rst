=============
Fournisseurs
=============

Le répertoire fournisseurs centralise les informations de tous vos
fournisseurs et leur historique d'achat.

Créer un fournisseur
====================

1. Allez dans :menuselection:`Achats --> Fournisseurs`
2. Cliquez sur **Nouveau**
3. Renseignez les informations du fournisseur

Informations du fournisseur
============================

Informations générales
----------------------

- **Raison sociale**
- **Adresse** : rue, code postal, ville, pays
- **Téléphone** et **Email**
- **Site web**

Informations commerciales
-------------------------

- **Délai de livraison** habituel
- **Conditions de paiement** négociées
- **Remises** accordées
- **Devise** de facturation

Informations fiscales
---------------------

- **SIRET / SIREN**
- **Numéro de TVA** intracommunautaire
- **RIB / IBAN** pour les paiements

Historique fournisseur
======================

Depuis la fiche fournisseur, consultez :

- **Commandes** passées
- **Factures** reçues
- **Paiements** effectués
- **Solde** fournisseur (dettes ouvertes)
