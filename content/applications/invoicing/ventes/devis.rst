=====
Devis
=====

Les devis sont des propositions commerciales envoyées à vos clients
avant la facturation. Ils peuvent être transformés en factures une fois acceptés.

Créer un devis
==============

Pour créer un nouveau devis :

1. Allez dans :menuselection:`Ventes --> Devis`
2. Cliquez sur **Nouveau**
3. Sélectionnez le **client**
4. Ajoutez les **lignes de devis** (produits ou services)
5. Définissez les **conditions de paiement**
6. Cliquez sur **Sauvegarder**

Contenu du devis
----------------

Chaque devis contient les informations suivantes :

- **En-tête** : numéro de devis, date, référence client
- **Client** : nom, adresse, contact
- **Lignes de détail** : description, quantité, prix unitaire, TVA, montant
- **Totaux** : sous-total HT, TVA, total TTC
- **Conditions** : validité du devis, conditions de paiement
- **Notes** : conditions générales de vente

Envoyer un devis
=================

Une fois le devis finalisé, vous pouvez l'envoyer au client :

- **Par email** : génère un PDF et l'envoie automatiquement
- **Télécharger en PDF** : pour impression ou envoi manuel

Transformer un devis en facture
===============================

Lorsque le client accepte le devis :

1. Ouvrez le devis validé
2. Cliquez sur **Créer la facture**
3. La facture est générée automatiquement avec les mêmes lignes

.. note::
   Le devis original reste archivé et lié à la facture pour la traçabilité.

États du devis
==============

Un devis peut avoir les états suivants :

- **Brouillon** : en cours de rédaction
- **Envoyé** : transmis au client
- **Accepté** : validé par le client
- **Refusé** : décliné par le client
- **Annulé** : annulé par l'émetteur
- **Facturé** : transformé en facture
