======
Avoirs
======

Un avoir (note de crédit) est un document comptable qui annule
partiellement ou totalement une facture précédemment émise.

Quand émettre un avoir
======================

Un avoir est nécessaire dans les cas suivants :

- **Erreur sur la facture** : prix, quantité ou désignation incorrects
- **Retour de marchandise** : le client retourne les produits
- **Remise commerciale** : accord d'une réduction après facturation
- **Annulation de vente** : la vente est annulée après facturation

Créer un avoir
==============

Depuis une facture existante
----------------------------

1. Ouvrez la facture concernée
2. Cliquez sur **Créer un avoir**
3. Choisissez le type :

   - **Avoir total** : annule l'intégralité de la facture
   - **Avoir partiel** : corrige uniquement certaines lignes ou montants

4. Ajustez les lignes si nécessaire
5. Validez l'avoir

Manuellement
------------

1. Allez dans :menuselection:`Ventes --> Avoirs`
2. Cliquez sur **Nouveau**
3. Référencez la facture d'origine
4. Saisissez les lignes de l'avoir
5. Validez

.. note::
   L'avoir suit la même séquence de numérotation dédiée (AVO-XXXX-XXXX)
   et est automatiquement lié à la facture d'origine.

Remboursement
=============

Après émission de l'avoir, vous pouvez procéder au remboursement :

- **Remboursement direct** : virement ou autre moyen de paiement
- **Déduction sur prochaine facture** : le montant de l'avoir est déduit
  de la prochaine facture du client
