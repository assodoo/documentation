=======
Société
=======

Configurez les informations de votre société. Ces données apparaissent
automatiquement sur tous vos documents commerciaux.

Informations légales
====================

1. Allez dans :menuselection:`Configuration --> Société`
2. Renseignez les champs suivants :

- **Raison sociale** : nom officiel de l'entreprise
- **Forme juridique** : SARL, SAS, EI, auto-entrepreneur, etc.
- **Capital social** (si applicable)
- **SIRET** : numéro d'identification (14 chiffres)
- **SIREN** : numéro d'identification (9 chiffres)
- **Code APE/NAF** : code d'activité
- **RCS** : numéro de registre du commerce
- **Numéro de TVA** intracommunautaire

Coordonnées
===========

- **Adresse** du siège social
- **Téléphone**
- **Email**
- **Site web**

Informations bancaires
======================

- **Nom de la banque**
- **IBAN**
- **BIC/SWIFT**

.. note::
   Les coordonnées bancaires peuvent être affichées sur vos factures
   pour faciliter le paiement par virement.

Personnalisation des documents
==============================

- **Logo** de l'entreprise (affiché sur devis, factures, avoirs)
- **Couleur principale** des documents
- **Mentions légales** en pied de page
- **Conditions générales de vente** par défaut
